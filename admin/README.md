# Yang181969 Comment Admin

独立留言管理后台，部署到 GitHub Pages 后使用：

```txt
https://admin.yang181969.com
```

后端 API：

```txt
https://comment.yang181969.com
```

管理员 token 只保存在服务器 `.env` 和私人密码管理器中，不要提交到本仓库。

## 留言线程管理

后台按顶级留言线程展示数据，回复固定显示在所属顶级留言内部的一层列表中，不进行无限嵌套。回复另一条回复时，`@被回复人` 表示真正的回复对象。

顶级留言和每条回复都使用自身的 id、身份、状态和点赞数，可以分别执行回复、隐藏、删除和恢复操作。状态筛选保留完整线程上下文，因此即使只有某条回复匹配，仍能看到它所属的顶级留言和同线程的其他回复。

分页按顶级线程计算。管理操作后会保持当前状态筛选并重新加载当前页；若当前页已经超过新的总页数，页面会自动回到最后一个有效页，无数据时回到第 1 页显示空状态。只有后端真正返回 HTTP 401 时才会清除当前管理员登录状态。
